# MultiTeacherCodex

MultiTeacherCodex is a TypeScript MCP server that sends a draft generated by ChatGPT to other frontier models for critique, then feeds that critique back to ChatGPT so it can revise and improve its final answer.

```text
User question
  → ChatGPT draft
  → Original question + ChatGPT answer + "Find anything incorrect or problematic"
  → Critique and revision guidance from external frontier models
  → ChatGPT revises the final answer using the feedback
```

The external models do not generate the final answer on ChatGPT's behalf. They only identify factual errors, logical issues, omissions, misunderstood requirements, and concrete revision instructions.

## Installation and Usage

Clone the public GitHub repository and run it with `npx` from inside the repository. No global installation is required.

```bash
git clone https://github.com/genji970/multiteachercodex.git
cd multiteachercodex
npx -y .
```

You can also run all three commands in a single line.

```bash
git clone https://github.com/genji970/multiteachercodex.git && cd multiteachercodex && npx -y .
```

`npx -y .` runs the current repository's `bin` entry point, `dist/cli.js`. If the required runtime dependencies are missing during the first launch, the CLI automatically runs the following command inside the repository before starting the server:

```bash
npm install --omit=dev --package-lock=false
```

Users do not need to run `npm install` manually or publish the package to npm.

During the first launch, the CLI asks for a review provider, API key, and reviewer model ID. The configuration is stored at:

```text
~/.multiteachercodex/config.json
```

After the initial setup, start the server from the repository directory with:

```bash
npx -y .
```

To change or reset the configuration:

```bash
npx -y . --setup
npx -y . --reset
```

To run the server on a different port:

```bash
npx -y . --port 9000
```

## Fully Non-Interactive Setup with Environment Variables

Instead of using the interactive setup, you can configure the server through a `.env` file or environment variables. At least one provider must be configured.

Anthropic:

```env
ANTHROPIC_API_KEY=...
ANTHROPIC_MODEL=...
```

Gemini:

```env
GEMINI_API_KEY=...
GEMINI_MODEL=...
```

OpenRouter or another OpenAI-compatible provider:

```env
OPENAI_COMPATIBLE_BASE_URL=https://openrouter.ai/api/v1
OPENAI_COMPATIBLE_API_KEY=...
OPENAI_COMPATIBLE_MODELS=provider/model-a,provider/model-b
```

Environment variables and the `.env` file in the current directory take precedence over the saved user configuration.

## Server Endpoints

Default MCP server endpoint:

```text
http://localhost:8787/mcp
```

Health-check endpoint:

```text
http://localhost:8787/
```

To connect the MCP server remotely from the ChatGPT app, expose the local server through an HTTPS URL and append `/mcp` to the generated address.

```bash
npx -y ngrok http 8787
```

Example:

```text
https://YOUR-DOMAIN.ngrok.app/mcp
```

## Processing Flow in ChatGPT

The MCP server instructions ask ChatGPT to follow this sequence:

1. Internally generate a complete draft response to the user's question.
2. Call the `review_chatgpt_answer` tool.
3. Evaluate the valid criticisms returned by the external reviewers.
4. Revise its own answer using the relevant feedback.
5. Return only the revised final answer, without exposing the review process.

## MCP Tool

### `review_chatgpt_answer`

Input:

```json
{
  "original_question": "The user's original question",
  "chatgpt_answer": "The draft generated by ChatGPT",
  "focus": "Optional review focus"
}
```

Core prompt sent to the external review models:

```text
[Original User Question]
{original_question}

[ChatGPT Answer]
{chatgpt_answer}

[Task]
Find anything incorrect or problematic in the ChatGPT answer above.
```

The tool returns structured critiques from each reviewer, along with a `revision_instruction` that ChatGPT can use when rewriting its answer.


```bash
npx -y .
```

## Important Notes

* The original user question and ChatGPT draft are sent to the external API providers configured by the user.
* ChatGPT Plus or Pro subscriptions do not include usage fees for external model APIs.
* Review models can also make mistakes, so ChatGPT is instructed to evaluate the feedback rather than copy it blindly.
* A publicly hosted deployment should add user authentication, API-key encryption, rate limiting, and a privacy policy.
